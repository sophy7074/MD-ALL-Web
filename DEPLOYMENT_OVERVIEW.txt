🔧 CONFIGURATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Key Settings (in .env file):

  AUTH_ENABLED=true              # Enable authentication
  AUTH_TYPE=ldap                 # ldap, sso, or local
  ADMIN_PASSWORD=changeme        # ⚠️  CHANGE THIS!
  
  MAX_WORKERS=4                  # Concurrent analyses
  MAX_MEMORY_GB=16              # Per-worker memory
  UPLOAD_MAX_SIZE_MB=500        # File size limit
  
  FORCE_HTTPS=true              # Require HTTPS
  SESSION_TIMEOUT=3600          # 1 hour timeout
  AUDIT_ENABLED=true            # Log all activities

See .env.example for all 50+ configuration options.
